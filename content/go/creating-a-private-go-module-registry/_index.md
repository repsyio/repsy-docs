title = "Creating a Private Go Module Registry"
weight = 810
description = "Register to get a default Go module registry, then create more registries or change the settings of existing ones."
+++

Before creating a registry, you need to {{< product "cloud" >}}[register to Repsy](https://repsy.io) with a username, password, and e-mail. When you register, Repsy will create a `default` registry for you.{{< /product >}}
In the Go section, you can create new registries and change the settings for existing ones whenever you need.
