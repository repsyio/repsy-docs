title = "Creating a Private PyPI Registry"
weight = 610
description = "Register to get a default PyPI registry, then create more PyPI registries or change the settings of existing ones."
+++

Before creating a registry, you need to [register to Repsy]({{< relref "/getting-started/creating-your-first-repository" >}})  with a username, password, and e-mail. When you register, Repsy will create a `default` registry for you.
In the PyPI section, you can create new registries and change the settings for existing ones whenever you need.
