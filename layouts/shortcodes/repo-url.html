{{- /* Base URL of the Repsy repository server for the current page's product, so that one page can be shared between Repsy Cloud and Repsy OS. Use the markdown notation, {{% repo-url %}}, so that the output takes part in the Markdown rendering and `` is escaped inside code spans and code blocks. {{% repo-url %}} Cloud: https://repo.repsy.io/ {{% repo-url path="helm" %}} Cloud: https://repo.repsy.io/helm/ {{% repo-url scheme="false" %}} Cloud: repo.repsy.io/ {{% repo-url scheme="false" account="false" %}} Cloud: repo.repsy.io (the host only) UNCONFIRMED for Repsy OS: the OS UI shows `/` without a username segment, but the exact URL format of each protocol is not confirmed.
