Before creating a repository, you need to {{< product "cloud" >}}[register to Repsy](https://repsy.io/) with a username, password, and e-mail. When you register, Repsy will create a `nuget` repository for you and will publish a sample package under it! This is how fast you can get started.{{< /product >}}{{< product "os" >}}have access to your Repsy Open Source instance.{{< /product >}}

In the NuGet section, you can create new repositories and change the settings for existing ones whenever you need.
