# Repositories

This section is about the day-to-day work with the repositories of a Repsy Open Source instance, once they exist: how an
administrator changes their settings, and how everybody browses what they contain and how an administrator deletes it.
To create a repository, see [Creating Your First Repository](../getting-started/creating-your-first-repository/).

- [Configuring Repository Settings](configuring-repository-settings/) explains every section of the settings page of a
  repository: visibility, package override, version allowance, signing, renaming, the Docker cleanup actions and deleting
  the repository.
- [Browsing and Deleting Packages](browsing-and-deleting-packages/) shows the package pages of the web UI, and what
  deleting a package, a version, an image or a tag removes.
